 Assistant Vocal Local (Alexa-like)
Ce projet consiste à créer un assistant vocal local, similaire à Alexa, Google Home ou Siri. Il détecte un mot-clé déclencheur "Alexa", transcrit l'audio en texte grâce à Whisper, interprète la question avec LlamaFile, puis génère une réponse vocale via une bibliothèque de text-to-speech.

🛠️ Technologies utilisées :
✅ Python
✅ Sklearn / TensorFlow
✅ Matplotlib, Seaborn, Numpy
✅ Whisper (transcription audio)
✅ Espeak ou autre TTS (Text-to-Speech)

🚀 Fonctionnalités :
🎤 Détection d'un mot-clé (ex: "Ok Google")
📝 Transcription automatique de l'audio
🧠 Interprétation et réponse via LlamaFile
🔊 Synthèse vocale pour donner une réponse à l’utilisateur
